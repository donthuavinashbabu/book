RandomStringUtils.randomAlphanumeric

static from RandomStringUtils examples
public static String randomAlphanumeric(int count)

Description

Creates a random alphanumeric string (letters and digits) of the requested length. Equivalent in spirit to random(count, true, true) with a dedicated API.

Parameters

NameTypeDescription
countintDesired length of the string

Returns

String — alphanumeric random value.

Code from this repository

String randomString3 = RandomStringUtils.randomAlphanumeric(10);
log.info("randomString3={}", randomString3);
// sample: randomString3=wk1ILav9Eb
