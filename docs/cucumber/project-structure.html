Project structure

Layout of the cucumber module and Maven example project.

Repository paths

PathRole
book/cucumber/ Topic root; table of contents
book/cucumber/cucumber/ Maven project (groupId com.book, artifact cucumber)
.../src/main/java/com/service/ Application code under test (Calculator)
.../src/test/resources/features/ Gherkin .feature files
.../src/test/java/com/step/defs/ Step definition classes (glue)
.../src/test/java/com/features/ JUnit Platform suite runner
