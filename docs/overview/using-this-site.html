Using this site

How the left navigation and topic pages work.

Left menu

  • Overview — site-wide pages about the Book repo and this documentation.
  • Guides & notes — quick links (Java errors, preparation, misc, NFRs). Use the sidebar filter to find a note by title; note links open on GitHub or Drive in a new tab.
  • Topic sections (for example Apache Commons Lang3) — pages for one book/<topic>/ module: intro, setup, API-style docs, and examples.

Expand and collapse

Sections start collapsed. Click a main section title or its chevron to expand or collapse. The section for the current page stays open. Clicking a submenu link only opens that page; it does not collapse the menu.

Filter

Use the search box at the top of the sidebar to filter menu labels. Matching sections stay visible so you can jump quickly.

Adding a new topic

When documenting another module:

  1. Create docs/<topic-id>/ with an index.html and related pages.
  2. Add a new section in docs/js/docs.js (NAV) pointing at those pages.
  3. Link the topic from Topics and optionally from the home page.
