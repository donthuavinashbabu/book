Class overview

org.apache.commons.lang3.RandomStringUtils generates random String values from letters, digits, or a custom character set. It is useful for test data, temporary tokens, and sample identifiers (not cryptographic secrets).

For security-sensitive tokens prefer SecureRandom / purpose-built libraries. RandomStringUtils is for convenience and test data.
