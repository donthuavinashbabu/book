RandomStringUtils.randomAlphabetic

static from RandomStringUtils examples
public static String randomAlphabetic(int count)

Description

Creates a random string containing only alphabetic characters (A–Z, a–z) of the requested length.

Parameters

NameTypeDescription
countintDesired length of the string

Returns

String — alphabetic-only random value.

Code from this repository

String randomString2 = RandomStringUtils.randomAlphabetic(10);
log.info("randomString2={}", randomString2);
// sample: randomString2=HsOnseHKUN
