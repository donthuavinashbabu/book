## Traditional problem:
- We have multiple tools for Data engineering, data science, and data analysis
- All the tools are from different vendors and are not integrated with each other
- To solve this problem, microsoft created `Fabric` which is `All-in-One Analytics Solution`
- Fabric cover everything like data movement, data engineering, data science, real time analytics, data warehousing, power BI, etc.
- All data is in `One Lake`
- `One Lake` is central data storage for all data
